# 哆咪 Domi 的成长日记 · 微信小程序

这是从现有哆咪网站迁移的原生微信小程序，使用 WXML / WXSS / JavaScript，无需安装第三方依赖，也不依赖网页嵌套。

## 打开项目

1. 打开微信开发者工具，选择“导入项目”。
2. 项目目录选择 `D:\Project\domi_web\miniprogram`。
3. 本地体验可选择测试号/无 AppID 模式；真机预览、上传和发布需确认项目使用自己的正式 AppID。
4. 编译即可看到首页，通过底部五栏切换内容。

- 首页：哆咪是虎斑猫，妈妈是流浪蓝猫；2026-07-14 出生、2026-09-05 到家；动态计算出生及到家天数。
- 成长：9.10 0.90 kg、9.26 1.40 kg、10.7 1.75 kg、10.17 2.00 kg、10.31 2.40 kg、11.8 2.50 kg、11.19 2.85 kg；展示最新体重、变化和最近八次体重折线图。横轴刻度采用相同的时间间隔，数据点距离按实际相隔天数计算，完整列表保留全部记录。
- 事件：出生、准备用品、到家、见朋友、PCR 检查、第一次驱虫、第一针疫苗、11.22 第二针疫苗，支持健康事件筛选。

- 记录展示：保留历史记录及之前的本机记录，成长页与事件页不再提供新增入口。

## 数据与照片

初始内容集中在 `utils/seed.js`，照片位于 `assets/`。图片从网站当前版本复制并按比例压缩，以控制小程序包体；未裁切或重新旋转。

新增记录使用微信本地缓存 `domi-diary-records-v1`，仅保存在当前设备，不会跨设备同步。清理微信缓存或删除小程序可能导致本机新增记录丢失。

事件日期不可早于生日或晚于今天；每天限一条体重记录。已有历史内容不会因新增记录而被覆盖。分享卡片指向首页，原始日记随小程序包一起分发。

## 验证与发布

在仓库根目录运行 `node scripts/verify-miniprogram.cjs`，检查配置、页面文件、模板事件、资源引用、包体大小、数据和新增/删除逻辑。

包体仍控制在 2 MiB 内，七张照片均保持网站原始比例。本机微信官方 WXML / WXSS 编译器可用于编译检查；模拟器和真机体验需在开发者工具中实际确认。

正式发布前，在微信开发者工具中替换真实 AppID，完成登录、编译、真机预览并上传体验版，再由小程序后台提交审核。没有实际完成预览/审核前，不应将此项目描述为已上线的小程序。
