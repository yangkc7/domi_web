# 哆咪 Domi 的成长日记

记录小虎斑猫哆咪的成长、日常与珍贵瞬间。本仓库包含网页版和原生微信小程序。

- [访问网页版](https://yangkc7.github.io/domi_web/)
- [查看微信小程序源码](miniprogram/)
- [小程序详细使用说明](miniprogram/README.md)

## 微信小程序

小程序使用 WXML、WXSS 和 JavaScript 开发，无需安装 npm 依赖，也无需配置云开发。整体采用奶油白、雾蓝和蜜桃色，中文与数字使用圆润的站酷快乐体，英文页眉保留原有字体。

底部设有五个栏目，以大字方块按钮切换：

| 栏目 | 内容 |
| --- | --- |
| 首页 | 哆咪简介、生日、到家日、最新体重、陪伴天数和最近事件 |
| 成长 | 历次称重、体重变化及最近八次记录的折线图 |
| 事件 | 出生、到家、检查、驱虫和疫苗等事件，支持健康档案筛选 |
| 日常 | 生活照片与日常故事 |
| 相册 | 纯图片展示，保留原图比例，按屏幕宽度排两至三列，支持点按查看大图 |

折线图横轴按实际相隔天数定位数据点，并使用相同时间间隔的刻度。体重数字位于折线上方；最新称重点以蜜桃色突出显示。

### 在微信开发者工具中打开

1. 下载或克隆本仓库。
2. 打开微信开发者工具，选择“导入项目”。
3. 项目目录选择仓库中的 **`miniprogram` 文件夹**，而非仓库根目录。
4. 确认 AppID 配置：本地体验可按工具支持选择测试号；真机预览、上传和发布需要使用自己的正式 AppID，并具备开发权限。
5. 点击“编译”，通过底部五个栏目浏览。

当前是以展示记录为主的版本，成长页和事件页已移除新增入口，未接入家庭共享或云端同步。早期版本保存在本机的记录仍会显示，但不会同步到其他设备。

源码上传 GitHub 不代表小程序已在微信上线。正式发布仍需完成账号资料、备案、真机测试、代码上传和微信审核。

### 更新记录与照片

- 基本信息、体重和事件数据：[miniprogram/utils/seed.js](miniprogram/utils/seed.js)。
- 小程序照片：`miniprogram/assets/`，使用完整宽高比显示。
- 更新源数据后重新编译；已发布的小程序还需上传新版本并审核发布。
- 网页版与小程序使用独立文件，更新小程序数据不会自动更新网页版。

### 本地检查

在仓库根目录运行：

```sh
node scripts/verify-miniprogram.cjs
```

检查包括页面配置、事件绑定、图片引用、体重记录、折线图时间比例、本机存储及包体大小。

## 项目目录

| 路径 | 用途 |
| --- | --- |
| `dist/` | 网页版页面、样式及资源，供 GitHub Pages 发布 |
| `miniprogram/` | 微信小程序源码与导入配置 |
| `font-sources/` | 开源字体源文件及授权说明 |
| `scripts/` | 小程序检查及离线字体生成脚本 |
| `.github/workflows/pages.yml` | 网页版的 GitHub Pages 发布流程 |
